# BuzzMap

BuzzMap is a gamified first-year onboarding platform designed to help incoming Georgia Tech students navigate every step of the transition to college. Instead of searching through scattered emails and websites, students progress through guided milestones—from paying their enrollment deposit and applying for housing to registering for classes and moving into campus.

## Features

- Gamified onboarding journey
- Personalized milestone checklist
- Registration guidance
- Campus navigation
- XP, levels, and achievements
- Calendar integration
- Avatar customization

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
